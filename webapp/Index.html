예방지도 · 보충지도 · 추가학습 선정 명단 관리, 출석부 및 가정통신문(안내문·확인서) 작성 프로그램
🗂 프로그램 개요

이 프로그램은 최소 성취수준 미달 학생을 대상으로 예방지도, 보충지도, 추가학습 세 가지 지도 유형별로 선정 명단을 관리하고, 지도 출석부와 가정통신문(안내문·확인서)을 작성·출력할 수 있는 웹 기반 도구입니다.
프로그램을 실행하면 바로 사용할 수 있으며, 입력한 학생 데이터는 외부로 전송되지 않습니다. (새 버전 확인을 위한 업데이트 확인만 인터넷을 사용합니다.)

📥 Step 1 — 엑셀 양식 다운로드
  • 상단 탭(예방지도 / 보충지도 / 추가학습)에서 해당 유형을 선택합니다.
  • 1학기 / 2학기 버튼으로 학기를 선택한 뒤, 양식 다운로드 버튼을 클릭합니다.
  • 다운로드된 .xlsx 파일을 엑셀(또는 한셀)로 엽니다.
  • 학년 · 반 · 번호 · 이름을 입력하고, 해당 과목 칸에 ○를 입력합니다. 1학년과 2학년 학생을 한 시트에 함께 입력해도 됩니다.
  • 파일을 .xlsx 형식으로 저장합니다.
💡 과목 입력 방법: 과목명 열에 ○, O, 1, Y 중 하나를 입력하면 선정으로 인식됩니다. 빈 칸이면 미선정입니다.
📤 Step 2 — 파일 업로드
  • 작성된 파일을 파일 업로드 탭의 업로드 영역에 끌어다 놓거나 클릭하여 선택합니다.
  • 지원 형식: .xlsx · .xls · .xlsm
  • 업로드 후 자동으로 데이터가 파싱되며, 학기가 자동 감지됩니다.
🎨 추가학습 — 타 교과(음악·미술·체육 등) 과목 관리
  • 추가학습 탭의 파일 업로드 화면 맨 위에 "타 교과 과목 관리" 카드가 있습니다.
  • 기본으로 음악·미술·체육이 포함되어 있고, 필요하면 입력창에 과목명을 적고 ＋ 과목 추가로 얼마든지 더 추가할 수 있습니다(예: 정보, 진로와 직업 등).
  • 추가한 과목은 양식 다운로드·업로드 인식·전체 명단·선정 결과·통계·출석부·가정통신문 전 영역에 자동으로 반영됩니다.
  • 더 이상 필요 없는 커스텀 과목은 칩 옆의 ✕ 버튼으로 제거할 수 있습니다(음악·미술·체육 기본 3과목은 고정이며 제거되지 않습니다).
  • 예방지도·보충지도 탭은 최소 성취수준 대상 7과목(공통국어·수학·영어·사회·과학·과학탐구실험·한국사)만 그대로 사용합니다.
📋 전체 명단 / ✅ 선정 결과 / 📊 통계 탭
  • 전체 명단: 학년·반 필터(학년 전체 또는 특정 학년의 특정 반), 선정 여부 필터, 이름 검색을 지원합니다. 선정 학생은 노란색으로 표시됩니다.
  • 선정 결과: 하나 이상 과목에 선정된 학생 목록과 선정 과목을 보여줍니다.
  • 통계: 과목별 선정 인원과 학년·반별 현황(학년별 소계 포함)을 확인합니다.
  • 각 탭에서 🖨 인쇄 및 ⬇ 엑셀 내보내기를 사용할 수 있습니다.
  • 통계 탭의 ⬇ 엑셀 파일에는 통계 시트와 함께, 학년·반별로 선정 학생과 선정 과목을 정리한 반별 명단 시트가 들어 있습니다.
📅 출석부 탭 사용 방법
  • 과목명을 선택하면 해당 과목 선정 학생만 표시됩니다.
  • 지도교사 이름, 총 운영 시수, 차시 수를 입력합니다.
  • 차시별 운영방법을 드롭다운에서 선택합니다. 새 운영방법은 운영방법 추가 입력란에서 추가할 수 있습니다.
  • 학생별 구분(일반학생, 학생선수, 이주배경학생 등)을 선택합니다.
  • 참여 차시 칸에 참여한 차시 수를 직접 입력하면 총 시수가 자동 계산됩니다.
  • 🔄 출석부 생성/갱신 버튼으로 최신 학생 목록을 반영합니다.
  • 인쇄 시 A4 가로 방향으로 최적화되어 출력됩니다.
📨 가정통신문 탭 사용 방법
  • 출석부 탭 옆에 있으며, 열면 그 학기에 선정된 학생만 자동으로 뽑혀 1인당 2페이지(① 안내문, ② 개인별 확인서)가 생성됩니다.
  • 학년·반 필터로 특정 학년 또는 특정 반만 골라 만들 수 있고, 🔄 생성/갱신으로 최신 선정 결과를 다시 불러올 수 있습니다.
  • 확인서(2페이지)에는 학생의 학년·반·번호·이름·선정 과목·과목별 시수/운영방법이 자동으로 채워지며, "참여 희망원"의 (학년)(반)(번)·학생 성명도 자동 입력됩니다(서명란만 비워둠).
  • 모든 문구는 클릭 후 바로 수정할 수 있습니다. 안내문의 발송일자·학교장·연락처 등 공통 항목을 한 학생 것만 고쳐두고 🔁 공통 항목 일괄 적용을 누르면 전체 학생에게 동일하게 반영됩니다.
  • 🖼 학교 로고 업로드 버튼으로 이미지를 올리면 안내문 상단 학교명 칸에 워터마크로 표시되며, 예방지도·보충지도·추가학습 전체에 공통 적용됩니다(다시 생성되므로 로고는 먼저 올려두는 것을 권장). ✕ 로고 제거로 없앨 수 있습니다.
  • 🖨 인쇄 시 학생별로 자동 페이지 나눔되어 1인당 정확히 2페이지, 한 장에 한 페이지씩 출력됩니다.
  • 다른 탭으로 이동해도 만들어 둔 가정통신문(수정 내용 포함)은 그대로 유지되며, 파일을 새로 업로드하면 초기화됩니다.
✅ 이수 관리 (예방지도 → 보충지도·추가학습 → 이수 결과)
  • 상단 이수 관리 탭에서 ＋ 새 과목을 누르고, 지도교사별·과목별로 하나씩 만듭니다.
  • ① 기본 정보: 학년도·학기·과목명·학점·교과 구분, 학생 구분별 연계율, 운영 시수, 운영 방법을 정합니다. 예방지도 인정 상한의 계산 방식(학점×3 또는 기존 엑셀 방식)은 학교 기준에 맞게 고릅니다.
  • ② 예방지도 출석: 예방지도 탭에 올린 선정 명단에서 그 과목 학생을 가져옵니다. 참여한 날짜(예: 5/14)를 적으면 시수와 운영 기간이 계산됩니다.
  • ③ 보충·추가 명단: 학기 말 나이스에서 내려받은 대상자 파일을 올리면 학업 성취율 미도달 → 보충지도, 과목 출석률만 미도달 → 추가학습으로 자동으로 나뉩니다.
  • ④⑤ 출석: 학생별로 참여한 날짜(예: 7/14)를 칸에 적습니다. 머리글에 날짜를 넣고 ‘↓’를 누르면 그 회차 빈칸이 한 번에 채워집니다. 예방지도 인정 시수(학생 구분별 상한 이내)를 더해 운영 시수의 2/3 이상이면 충족입니다.
  • ⑥ 이수 결과: 엑셀(이수결과·출석부 4개 시트)로 내보내거나 인쇄합니다.
  • 담당 선생님 취합: 각 선생님이 📤 과목 파일 내보내기로 만든 파일을 담당자가 📥 과목 파일 불러오기로 모두 넣으면 🏫 학교 전체 취합에서 한 번에 정리되고 엑셀로 받을 수 있습니다.
🔐 학교 웹앱(로그인)으로 쓸 때
  • 담당 선생님께 받은 아이디와 처음 비밀번호로 로그인하고, 처음 한 번 새 비밀번호를 정합니다.
  • 🏠 홈에 내 과목과 할 일(출석 미입력, 기준 미달 학생 등)이 나옵니다. 할 일을 누르면 바로 그 화면으로 갑니다.
  • 입력한 내용은 학교 구글 시트에 자동 저장되고, 담당 선생님 화면에 바로 반영됩니다. 과목 파일을 따로 보낼 필요가 없습니다.
  • 담당 선생님(관리자)은 학교 전체 현황, 👥 계정 관리, 선정 명단 올리기, 전체 이수결과 엑셀·시트 만들기를 할 수 있습니다.
  • 한 과목을 여러 선생님이 나눠 맡으면 기본 정보 → 담당 반에 반(예: 1~5)을 적어 두세요. 명단을 가져올 때 그 반 학생만 들어옵니다.
💾 저장과 백업
  • 이수 관리 내용과 마지막으로 올린 선정 명단은 이 PC에 자동 저장되어, 프로그램을 껐다 켜도 그대로 남습니다. 인터넷으로 전송되지 않습니다.
  • 프로그램을 켤 때마다 하루 한 번 자동 백업을 만들고 최근 30일치를 보관합니다(메뉴 파일 → 데이터 폴더 열기의 backups 폴더).
  • PC를 옮기거나 따로 보관할 때는 💾 전체 백업 파일 만들기로 파일을 만들고, 새 PC에서 ♻️ 백업 파일로 되돌리기로 불러옵니다.
⚠️ 주의: 가정통신문 화면에서 직접 고친 문구는 저장되지 않습니다. 고친 뒤에는 바로 인쇄해 두세요.
