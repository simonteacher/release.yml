# 학교 웹앱(구글 시트) 설치 방법

담당 선생님(관리자)이 **한 번만** 하면 됩니다. 15분 정도 걸립니다.
학교 구글 계정(또는 담당 선생님 구글 계정)으로 진행하세요. 이 계정의 구글 드라이브에 시트가 만들어지고, 모든 데이터가 여기에 저장됩니다.

## 1. 구글 시트 만들기
1. [Google 스프레드시트](https://sheets.new)에서 새 시트를 만들고 이름을 `최소성취 보장지도 DB`로 바꿉니다.
2. 이 시트는 **다른 선생님과 공유하지 마세요.** 선생님들은 웹앱으로만 들어오고, 시트는 담당자만 엽니다.

## 2. Apps Script에 코드 넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script**를 누릅니다.
2. 왼쪽 `Code.gs`의 내용을 모두 지우고, [webapp/Code.gs](Code.gs) 파일 내용을 붙여넣습니다.
   - GitHub 파일 화면 오른쪽 위의 **복사 버튼(Copy raw file)**을 누르면 전체가 복사됩니다.
3. 왼쪽 **파일 옆 ＋ → HTML**을 누르고 이름을 `Index`로 정합니다(대문자 I, `.html`은 자동으로 붙음).
4. 새로 생긴 `Index.html`의 내용을 모두 지우고, [webapp/Index.html](Index.html) 파일 내용을 붙여넣습니다.
5. 💾 저장(Ctrl+S)을 누릅니다.

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴(유형 선택) → **웹 앱**을 고릅니다.
3. 다음처럼 정합니다.
   - 설명: `최소성취 보장지도`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고 **액세스 승인**을 누릅니다.
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)** → **허용**을 누릅니다. 학교에서 직접 만든 스크립트라 나오는 안내입니다.
   - 이 스크립트는 **지금 이 시트 하나만** 읽고 씁니다.
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> "모든 사용자"로 해야 선생님들이 구글 로그인 없이 이 프로그램의 아이디·비밀번호로 들어올 수 있습니다. 주소를 알아도 로그인하지 않으면 아무 데이터도 볼 수 없습니다.

## 4. 처음 설정
1. 복사한 주소를 브라우저에서 엽니다.
2. **처음 설정: 관리자 계정 만들기** 화면에서 학교 이름, 이름, 아이디, 비밀번호를 정합니다.
3. 들어가면 **이수 관리 → 👥 계정 관리**에서 선생님 계정을 만듭니다. 아이디와 처음 비밀번호를 각 선생님께 알려 주면, 처음 로그인할 때 비밀번호를 직접 바꿉니다.
4. 구글 시트의 **예방지도 명단 · 보충지도 명단 · 추가학습 명단** 탭에 명단을 붙여넣습니다(아래 ‘명단 넣는 방법’). 선생님들은 자기 과목 학생만 볼 수 있습니다.
5. 과목은 선생님이 직접 만들거나, 담당자가 만들고 **기본 정보 → 담당 교사**에서 배정합니다.

## 5. 설치된 프로그램(exe)과 연결
웹앱 주소를 저장소의 `config.json`에 넣으면, 선생님 PC의 프로그램이 업데이트되면서 자동으로 이 웹앱을 엽니다.

```json
{
  "webappUrl": "https://script.google.com/macros/s/…/exec"
}
```

브라우저 즐겨찾기나 휴대폰 홈 화면에 주소를 추가해서 써도 됩니다.

## 웹앱 고친 내용 반영하기 (업데이트)
`index.html`을 고쳐 GitHub에 올리면 `webapp/Index.html`이 자동으로 다시 만들어집니다. 그다음 아래처럼 반영합니다.
1. Apps Script의 `Index.html`(서버를 고쳤다면 `Code.gs`도) 내용을 새 파일로 바꾸고 저장합니다.
2. **배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포**를 누릅니다.
   - **새 배포를 만들면 주소가 바뀌므로**, 꼭 기존 배포를 수정하세요. 이렇게 하면 주소는 그대로입니다.

## 명단 넣는 방법 (담당자)
프로그램에서 엑셀을 올리지 않고, **구글 시트 탭에 직접 붙여넣으면** 자동으로 연동됩니다(로그인할 때와 10분마다, 또는 명단 화면의 **🔄 시트에서 다시 불러오기**).

| 탭 | 넣는 내용 |
|---|---|
| 예방지도 명단 | 예방지도 선정 학생 |
| 보충지도 명단 | 학기 말 보충지도 대상(학업성취율 미도달) |
| 추가학습 명단 | 학기 말 추가학습 대상(출석률 미도달) |

- 첫 줄 머리글: `학년 | 반 | 번호 | 이름 | 과목명…` 그리고 선정된 과목 칸에 `○`(또는 `O`, `1`, 체크박스). 기존 엑셀 양식을 그대로 복사해 붙여넣어도 됩니다(위쪽 제목 줄이 있어도 괜찮음).
- 나이스 자료처럼 **한 줄에 한 과목**이면 `학년 | 반 | 번호 | 이름 | 과목` 형태도 됩니다. 반 칸이 병합되어 있어도 됩니다.
- 과목명 끝의 1·2로 학기를 자동 판단합니다. 과목명은 선생님들이 만든 과목명과 같아야 연결됩니다(국어1·영어1처럼 줄여 써도 공통국어1·공통영어1로 알아봅니다).
- 읽다가 문제가 있으면(머리글 없음, 같은 번호에 다른 이름 등) 대시보드 왼쪽 **명단·안내문 → 🔗 시트 연동** 화면에 안내가 나옵니다.

## 시트 구성 (자동으로 만들어짐)
| 탭 | 내용 |
|---|---|
| 계정 | 아이디, 이름, 역할. 비밀번호는 암호화된 값만 저장됩니다 |
| 과목 | 과목별 출석 기록(시트 칸 하나의 글자 수 한도 때문에 여러 칸에 나눠 저장) |
| 예방지도 명단 / 보충지도 명단 / 추가학습 명단 | 담당자가 붙여넣는 선정 명단(직접 고쳐도 됨) |
| 설정 | 학교 이름 등 |
| 기록 | 로그인, 과목 추가·삭제, 계정 변경 기록 |
| 이수결과(…) | 학교 전체 현황에서 **📄 시트에 이수결과 만들기**를 누르면 생기는 정리표 |

`과목` 탭의 데이터 칸은 손으로 고치지 마세요. 프로그램이 읽지 못하게 될 수 있습니다. 정리된 표가 필요하면 `이수결과` 탭을 쓰세요.

## 백업
구글 시트는 **파일 → 버전 기록**으로 이전 상태로 되돌릴 수 있습니다. 학기 말에는 **파일 → 사본 만들기**로 한 부 보관해 두세요.
