# 다른 학교용 템플릿 만드는 방법 (배포하는 선생님용, 한 번만 · 약 5분)

다른 학교 선생님들이 **사본 만들기** 한 번으로 시작할 수 있도록, 학교 데이터가 전혀 없는 **빈 템플릿 시트**를 만들어 링크로 공유합니다.
우리 학교 시트와는 완전히 별개의 파일이라, 템플릿을 통해 우리 학교 시트로 들어갈 길은 없습니다.

## 준비
- **배포 전용 개인 구글 계정**을 권합니다(새로 만들어도 됨). 공유 화면에 학교 계정 이름이 보이지 않고, 교육청 계정의 공유 제한도 피할 수 있습니다.
- 이 폴더의 파일 3개: `Code.gs`, `Index.html`, `appsscript.json`

## 순서
1. 배포 전용 계정으로 구글 드라이브에서 **새 스프레드시트**를 만들고 이름을 `최소성취수준 이수관리 (템플릿)`으로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다. 왼쪽 위 프로젝트 이름을 `이수관리`로 바꿉니다.
3. `Code.gs`의 내용을 모두 지우고, 이 폴더의 **Code.gs** 내용을 통째로 붙여넣습니다.
4. 파일 옆 **＋ → HTML**을 누르고 이름을 정확히 `Index`로 짓습니다(.html은 자동으로 붙음). 내용을 모두 지우고 **Index.html** 내용을 붙여넣습니다.
5. 왼쪽 **⚙ 프로젝트 설정 → ‘appsscript.json’ 매니페스트 파일을 편집기에 표시**에 체크합니다. 편집기에 생긴 `appsscript.json` 내용을 이 폴더의 **appsscript.json** 내용으로 바꿉니다(시간대가 서울로 맞춰집니다).
6. **저장(Ctrl+S)** 합니다. 시트 탭으로 돌아가 **새로고침**하면 맨 앞에 **‘시작하기’ 탭**과 위쪽 **🛠 이수 관리** 메뉴가 생깁니다.
   - 탭이 안 생기면 메뉴 **🛠 이수 관리 → ‘시작하기’ 탭 다시 만들기**를 누릅니다(처음 한 번 권한 승인).
7. **템플릿은 배포하지 않습니다.** 웹앱 배포는 사본을 만든 각 학교가 합니다. 템플릿에 명단이나 계정도 넣지 마세요.
8. 오른쪽 위 **공유 → 일반 액세스: 링크가 있는 모든 사용자(뷰어)** → **링크 복사**.
9. 복사한 링크 끝의 `/edit?usp=sharing`을 `/copy`로 바꿉니다. 이것이 다른 학교에 줄 **사본 만들기 링크**입니다.
   - 예: `https://docs.google.com/spreadsheets/d/문서ID/copy`
10. 시크릿 창(또는 다른 계정)에서 그 링크를 열어 사본을 만들고, ‘시작하기’ 탭 순서대로 한 번 해 보면 확인 끝.

## 다른 학교에 보낼 것
- 사본 만들기 링크 (위 9번)
- `최소성취수준_이수관리_설치·사용_가이드(다른학교용).pdf`
- `최소성취수준_이수관리_사용법_영상(다른학교용).mp4`
- (복사가 막힌 학교용) `Code.gs`, `Index.html` 파일 — 빈 시트의 Apps Script에 직접 붙여넣어도 똑같이 동작합니다.

## 새 버전이 나오면
- 템플릿의 `Code.gs`·`Index.html`을 새 파일로 바꿔 두면, 이후 복사하는 학교는 새 버전으로 시작합니다.
- 이미 쓰고 있는 학교는 각자 Apps Script에서 두 파일을 바꾸고 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 누릅니다(주소·데이터 그대로).
- 최신 파일은 GitHub 저장소의 `webapp/배포판/` 폴더에 자동으로 만들어집니다.
