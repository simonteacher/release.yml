구글 계정으로 학교 설정하기

구글에 로그인하면 프로그램이 학교 구글 시트를 만들고, 프로그램을 설치하고, 선생님들이 접속할 학교 주소까지 만들어 줍니다. 3분쯤 걸립니다.

학생 정보는 선생님 구글 드라이브의 시트에만 저장됩니다. 교육청(학교) 계정에서 막히면 개인 구글 계정으로 해 보세요.

이 프로그램에는 구글 연결 정보가 들어 있지 않아 이 방법을 쓸 수 없습니다. 아래 ‘학교 주소 연결’이나 ‘이 PC에서만 쓰기’를 이용해 주세요.

  • 구글 로그인
  • 학교 구글 시트 만들기
  • 프로그램 코드 넣기
  • 학교 웹앱 만들기
  • 웹앱 권한 허용

인터넷 창이 열렸습니다. 구글에 로그인한 뒤 권한 화면에서 모든 항목에 체크하고 [계속]을 눌러 주세요.

‘Google에서 확인하지 않은 앱’이 나오면 [고급] → [… (으)로 이동]을 누르면 됩니다. 창이 안 보이면 작업 표시줄의 인터넷 창을 확인하세요.

구글 설정 하나만 켜 주세요 (계정마다 처음 한 번)

  1. [설정 페이지 열기]를 누릅니다. 같은 구글 계정으로 로그인되어 있어야 합니다.
  2. Google Apps Script API 옆 스위치를 눌러 사용으로 바꿉니다.
  3. 여기로 돌아와 [켰어요, 계속하기]를 누릅니다. 반영까지 1분쯤 걸릴 수 있습니다.

인터넷 창에서 학교 웹앱의 권한을 허용해 주세요.

  1. [권한 검토] 또는 [액세스 승인]을 누르고 같은 구글 계정을 고릅니다.
  2. ‘Google에서 확인하지 않은 앱’이 나오면 [고급] → [… (안전하지 않음)(으)로 이동]을 누릅니다.
  3. [허용]을 누르면 프로그램이 알아서 다음으로 넘어갑니다.

선생님이 방금 만든 선생님 소유의 웹앱이라 나오는 안내입니다.

구글 없이 이 PC에서만 쓰기

설정 없이 바로 시작합니다. 자료는 이 PC에만 저장되고, 선생님들 자료는 ‘과목 파일’을 주고받아 모읍니다.

나중에 바꾸려면 위쪽 메뉴 [파일] → [학교 연결 설정]을 누르세요.
