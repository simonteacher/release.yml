# 구글 클라우드 앱 등록 (배포하는 선생님, 처음 한 번 · 약 20분)

다른 학교용 프로그램(ISU-Manager-Setup.exe)의 **[구글 계정으로 학교 설정하기]**가 동작하려면, 프로그램이 구글에 “이 프로그램이 로그인을 요청합니다”라고 알릴 수 있도록 앱을 한 번 등록해야 합니다. 무료입니다.

> 학교 업무 계정 말고 **배포 전용 개인 구글 계정**으로 하는 것을 권합니다. 로그인 화면에 이 계정의 이메일이 ‘개발자 연락처’로 보입니다.

## 1. 프로젝트 만들기
1. https://console.cloud.google.com 에 배포 전용 계정으로 들어갑니다. (처음이면 약관 동의)
2. 위쪽 **프로젝트 선택** → **새 프로젝트** → 이름 `isu-manager` → **만들기**.
3. 만든 프로젝트가 위쪽에 선택되어 있는지 확인합니다.

## 2. API 두 개 켜기
1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**.
2. `Google Drive API` 검색 → 들어가서 **사용**.
3. 다시 라이브러리에서 `Apps Script API` 검색 → **사용**.

## 3. 로그인 화면(OAuth 동의 화면) 만들기
1. 왼쪽 메뉴 **API 및 서비스 → OAuth 동의 화면**(또는 **Google 인증 플랫폼**) → **시작하기**.
2. 앱 정보: 앱 이름 `최소성취수준 이수관리`, 사용자 지원 이메일은 내 이메일 → 다음.
3. 대상: **외부** → 다음.
4. 연락처 정보: 내 이메일 → 다음 → 동의 체크 → **만들기**.
5. 왼쪽 **데이터 액세스** → **범위 추가 또는 삭제** → 아래를 찾아 체크하고 **업데이트** → **저장**.
   - `.../auth/userinfo.email`, `openid`
   - `.../auth/drive.file` (이 앱으로 만든 파일만 접근)
   - `.../auth/script.projects`
   - `.../auth/script.deployments`
   (목록에 없으면 아래 ‘직접 범위 추가’ 칸에 `https://www.googleapis.com/auth/script.projects` 처럼 붙여넣습니다.)
6. 왼쪽 **대상** → 게시 상태가 ‘테스트’로 되어 있으면 **앱 게시** → **확인**을 눌러 **프로덕션**으로 바꿉니다.
   - ⚠️ ‘테스트’ 상태로 두면 등록한 사람만 로그인할 수 있고, 로그인이 7일마다 풀립니다.
   - 심사(인증)는 받지 않아도 됩니다. 대신 로그인할 때 ‘Google에서 확인하지 않은 앱’ 안내가 나오고, 이 앱으로 로그인할 수 있는 계정이 100개까지입니다(학교마다 담당 선생님 1명만 로그인하므로 100개 학교).

## 4. 클라이언트(프로그램용 열쇠) 만들기
1. 왼쪽 **클라이언트**(또는 **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**).
2. 애플리케이션 유형: **데스크톱 앱**, 이름: `ISU 프로그램` → **만들기**.
3. 나오는 **클라이언트 ID**(…apps.googleusercontent.com)와 **클라이언트 보안 비밀번호**(GOCSPX-…)를 복사합니다. (JSON 다운로드도 됨)

## 5. 프로그램에 넣기 (GitHub Secrets)
공개 저장소에 그대로 올리면 GitHub가 막으므로, 저장소의 **Secrets**에 넣고 빌드할 때만 프로그램에 들어가게 합니다.
1. https://github.com/simonteacher/release.yml/settings/secrets/actions → **New repository secret**
2. Name `GOOGLE_CLIENT_ID`, Secret에 클라이언트 ID → **Add secret**
3. 다시 **New repository secret** → Name `GOOGLE_CLIENT_SECRET`, Secret에 클라이언트 보안 비밀번호 → **Add secret**
4. https://github.com/simonteacher/release.yml/actions/workflows/release.yml → **Run workflow** → 초록 **Run workflow**. 10분쯤 뒤 새 버전이 배포됩니다.

> 데스크톱 앱의 ‘보안 비밀번호’는 결국 프로그램 안에 들어가는 값이라 구글도 완전한 비밀로 취급하지 않습니다. 실제 안전장치는 각 학교 담당 선생님이 직접 로그인·허용하는 단계입니다.

## 6. 확인
1. https://github.com/simonteacher/release.yml/releases/latest/download/ISU-Manager-Setup.exe 를 받아 설치합니다.
2. 처음 화면에서 **구글 계정으로 시작** → 로그인·허용 → (처음 한 번) Apps Script API 스위치 켜기 → 웹앱 권한 허용.
3. 관리자 계정 만들기 화면이 나오면 성공입니다. 구글 드라이브에 ‘최소성취수준 이수관리 (학교 데이터)’ 시트가 생겨 있습니다.

## 문제가 생기면
| 화면에 나온 말 | 해결 |
|---|---|
| 이 프로그램에는 구글 연결 정보가 들어 있지 않아… | 5번을 아직 안 한 것입니다. |
| 프로그램 배포자의 구글 클라우드 설정에서 API가 꺼져 있습니다 | 2번의 API 두 개를 켰는지 확인합니다. |
| Apps Script API 사용 설정이 꺼져 있습니다 | 설정하는 선생님 계정에서 https://script.google.com/home/usersettings 의 스위치를 켭니다(프로그램이 안내함). |
| 액세스 차단됨 / 이 앱은 테스트 중 | 3-6번 ‘앱 게시’(프로덕션)를 합니다. |
| 웹앱을 배포하지 못했습니다 | 교육청(학교) 계정 정책일 수 있습니다. 개인 구글 계정으로 다시 해 봅니다. |
