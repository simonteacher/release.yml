이수 관리 프로그램

예방지도 → 보충지도·추가학습 → 최종 이수 결과까지, 교과 선생님은 출석 날짜만 적고 담당 선생님은 학교 전체를 한 화면에서 관리합니다. 학교 무료 프로그램입니다.

Windows 프로그램 받기

설치 후 처음 화면에서 학교 연결 방법을 고릅니다. 처음이라면 담당 선생님 시작 가이드 · 교과 선생님 접속 가이드(PDF)를 보세요. 2분짜리 시작 영상도 있습니다.

  1. 담당 선생님: ‘구글 계정으로 학교 설정하기’ → 구글 로그인·허용 → 학교 시트와 학교 전용 주소가 자동으로 만들어집니다.
  2. 교과 선생님: 담당 선생님이 보낸 안내문을 복사해 둔 채 프로그램을 켜면 우리 학교가 자동으로 나타납니다 → [이 학교에 연결] → 로그인. 인터넷 창이나 휴대폰에서 주소를 바로 열어도 됩니다.
  3. 학생 정보는 학교 구글 계정(또는 그 PC)에만 저장됩니다. 배포자는 어떤 정보도 받지 않습니다.
