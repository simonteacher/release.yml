# 최소 성취수준 보장지도 시스템

예방지도 · 보충지도 · 추가학습 선정 명단 관리, 출석부, 가정통신문(안내문·확인서), 그리고 예방지도 → 보충지도·추가학습 → **최종 이수 결과**까지 이어지는 이수 관리를 하는 Windows 프로그램입니다.
입력한 학생 데이터는 각 선생님 PC에만 저장되고 밖으로 전송되지 않습니다(인터넷은 새 버전 확인에만 사용).

- 데이터 위치: `%APPDATA%\최소성취수준보장지도\data\isu-data.json` (프로그램 메뉴 **파일 → 데이터 폴더 열기**)
- 자동 백업: 같은 폴더의 `backups` (하루 1개, 최근 30일)

## 설치 (선생님용)

1. [최신 버전 다운로드 페이지](https://github.com/simonteacher/release.yml/releases/latest)에서 최신 버전의 `AchievementGuidance-Setup-x.x.x.exe`를 내려받습니다.
2. 실행하면 바로 설치되고 바탕화면에 **최소성취수준보장지도** 아이콘이 생깁니다. 관리자 권한은 필요 없습니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다(서명되지 않은 학교 자체 프로그램이라 뜨는 경고입니다).

설치 후에는 새 버전이 나오면 프로그램이 자동으로 알려 줍니다.
- 프로그램을 켤 때, 그리고 켜 둔 상태에서 4시간마다 새 버전을 확인합니다.
- "지금 받기"를 누르면 백그라운드에서 내려받고, 다 받으면 "지금 다시 시작" 또는 "나중에(종료할 때 자동 설치)"를 고를 수 있습니다.
- 메뉴 **도움말 → 업데이트 확인**으로 직접 확인할 수도 있습니다.

## 학교 웹앱(구글 시트) 모드 — 2.0부터

담당 선생님이 구글 시트 + Apps Script로 학교 웹앱을 한 번 만들어 두면 다음처럼 바뀝니다.
- **교과 선생님:** 아이디·비밀번호로 로그인해 자기 과목만 입력합니다. 홈 화면에서 할 일이 보입니다.
- **담당자(관리자):** 학교 전체 현황, 계정 관리, 선정 명단 올리기, 전체 이수결과 엑셀·시트 정리를 맡습니다.
- **데이터:** 모두 담당자 구글 시트 한 곳에 모입니다. 과목 파일을 주고받아 취합할 필요가 없습니다.

설치는 [webapp/설치방법.md](webapp/설치방법.md)를 따라 하면 됩니다. `config.json`에 웹앱 주소를 넣기 전까지는 프로그램이 지금처럼 PC 저장 방식으로 동작합니다.

## 새 버전 배포 방법 (관리자용)

1. GitHub에서 `index.html`을 수정하거나, 새 파일로 교체(Add file → Upload files)합니다.
2. 커밋 메시지에 **변경 내용**을 적습니다. 이 문장이 선생님들 화면의 업데이트 알림에 그대로 표시됩니다.
   예: `출석부 엑셀에 차시별 날짜 포함`
3. 커밋하면 끝입니다. 약 5~10분 뒤 **Actions** 탭에서 빌드가 끝나고, **Releases**에 새 버전이 올라갑니다.
4. 이후 선생님들 프로그램이 새 버전을 감지해 알림을 띄웁니다.

버전 번호는 자동으로 붙습니다(`1.1.배포번호`). 큰 개편일 때는 `package.json`의 `"version"`을 `1.2.0`, `2.0.0`처럼 앞자리만 올리면 됩니다.

Actions 탭 → **빌드 및 배포** → **Run workflow**로 파일 수정 없이 다시 배포할 수도 있습니다(변경 내용 입력 가능).

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 프로그램 화면과 기능 전체(여기만 고치면 됨) |
| `main.js` | 창, 메뉴, 자동 업데이트, PC 저장·백업 처리 |
| `preload.js` | 화면이 PC 저장소를 쓰도록 연결 |
| `fonts/` | Pretendard 글꼴(OFL 라이선스) |
| `config.json` | 학교 웹앱 주소(비우면 PC 저장 방식) |
| `webapp/` | 학교 웹앱(Apps Script) 파일: `Code.gs`, `Index.html`(자동 생성), 설치 방법 |
| `package.json` | 프로그램 이름·버전·설치 파일 설정 |
| `.github/workflows/release.yml` | 커밋 시 자동 빌드·배포 |

## 개발자용

npm ci
npm start          # 바로 실행
npm run dist       # 설치 파일 만들기(Windows에서)
